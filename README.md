# 자막명 맞추기 (subrename)

미디어 파일과 자막 파일의 이름이 숫자만 같고 나머지는 다를 때, 자막 이름을 미디어 이름에 맞춰 바꾸는 오프라인 안드로이드 앱.

인터넷 권한이 없다. SAF(폴더 선택)로만 동작한다.

## 동작

1. 미디어·자막이 같이 있는 폴더를 고른다.
2. 파일명에서 **트랙 번호**를 뽑아 키로 쓴다. (아래 "트랙 번호 인식 규칙" 참고)  
   예: `TR7. 예시1(일본어).MP3` → 키 `7`  
   예: `MP3_01A 예시.mp3` → 키 `1a`
3. 같은 키를 가진 **미디어가 정확히 1개**이고 자막이 있으면, 자막을  
   `(미디어 stem).(자막 확장자)` 로 바꾸도록 제안한다.
4. 제안 목록에서 원하는 것만 선택해 적용한다.

### 트랙 번호 인식 규칙

위에서부터 먼저 맞는 것을 쓴다.

0. `MP3`, `MP4`, `M4A`, `320kbps`, `44.1kHz`, `24bit`, `1080p`, `x264` 같은 포맷/품질 표기는 먼저 지운다 (`MP3` 의 3 이 트랙으로 읽히는 것 방지)
1. `TR` / `Track` / `T` / `트랙` / `トラック` + 숫자 → `TR7`, `Track01`, `t3`, `트랙 5`
2. 이름 맨 앞의 숫자 → `01_`, `1-`, `01-`, `01A`, `1a`, `[01]`
3. 이름 중간에 구분자로 분리된 숫자 → `앨범 - 07 - 제목`
4. 모두 실패하면 모든 숫자 묶음을 `_` 로 연결 → `S01E12` → `1_12`

- 앞자리 0 은 무시한다 (`01` == `1`)
- 숫자 뒤 한 글자 알파벳은 소문자로 키에 포함한다 (`01A` == `1a` ≠ `1`)

### 예시

```
TR7. 예시1(일본어).MP3
TR7. 예시2(중국어).VTT
```

→ `TR7. 예시2(중국어).VTT` 를 `TR7. 예시1(일본어).VTT` 로 변경

### 지원 확장자

- 자막: `.vtt` `.srt` `.lrc` `.txt`
- 미디어: mp3, m4a, flac, wav, aac, ogg, opus, wma, mp4, mkv, avi, webm, mov, m4v 등 흔한 오디오/비디오

### 트랙명이 같을 때 (파일명-자막명 기준 변환)

같은 키(트랙명)를 가진 미디어가 2개 이상이면 번호만으로는 짝을 정할 수 없다.  
이때 **"파일명-자막명 기준으로 변환할까요?"** 확인창이 뜬다.

- **변환**: 미디어 확장자(`.wav` 등)를 뺀 이름이 가장 비슷한 것끼리 짝지어 제안 목록에 추가한다.
  각 제안에는 `파일명 일치도 %` 가 표시되니 낮은 것은 체크 해제하면 된다.
- **건너뛰기**: 변환하지 않고 충돌 경고로만 남긴다.

```
곡1.wav
곡1.wav.vtt   →  곡1.vtt
```

- 일치도 100% 부터 차례로 확정하는 1:1 매칭. 자막 1개는 미디어 1개에만 붙는다.
- 한 미디어에 확장자가 다른 자막(`.vtt`, `.srt`)은 각각 1개씩 붙을 수 있다.
- 일치도 50% 미만은 짝으로 인정하지 않고 "짝을 못 찾음" 경고로 남긴다.
- 유니코드 NFC 로 정규화해 비교한다 (한글 자모 분리 파일명 대응).
- 한 미디어에 확장자가 같은 자막이 2개 이상일 때도 같은 방식으로 처리한다.
- 바꿀 게 없는 그룹(이미 다 맞춰진 경우)은 묻지 않는다.

### 충돌 처리

- 같은 키에 미디어가 2개 이상 → 위의 파일명 기준 변환을 물어본다 (건너뛰면 경고)
- 바꿀 이름이 이미 존재 → 제안하지 않고 경고
- 이미 미디어 이름과 같은 자막 → 스킵

## 스택

- Kotlin 1.9.24, Jetpack Compose, AGP 8.5.2
- minSdk 29 / targetSdk 34
- 패키지: `com.ss2ux.subrename`

## 소스 구조

| 파일 | 역할 |
|------|------|
| `RenameLogic.kt` | 숫자 키 추출, 매칭, 파일명 유사도 매칭, 제안 생성 (순수 로직) |
| `AppViewModel.kt` | 폴더 URI, 스캔, 이름 변경 실행 |
| `Screens.kt` | 메인 UI |
| `MainActivity.kt` | 진입점, 폴더 선택기 |
